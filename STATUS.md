## What's broken / rough edges

- Self-deploy's final ACK can be lost when the daemon restarts itself
  (cosmetic; verify with a fresh `hello`).
- Auth's plaintext-on-wire is a loopback speed-bump, not crypto (HMAC/TLS is
  the documented upgrade).
- Config > Disk Image window won't live-update if the install/welcome flow
  changes the path while it's open (writes the same Preferences key; just no
  live mirror). Minor.
